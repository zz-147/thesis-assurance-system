# 老师端使用指南（1 分钟上手）

> 适用场景：同学在微信里把 `.docx` 发给你 → 你把文件存到一个文件夹 → 批量检查格式 → 把反馈发回给学生。
> 全部在本机处理，文档不会上传网络；检查格式不需要联网，也不需要登录。

## 1. 启动

**方式 A：项目目录（电脑已装 Python）**

双击项目根目录的 **`启动老师端.bat`**：

- 会自动打开浏览器到 `http://127.0.0.1:8765`
- 黑色窗口**不要关**；关掉窗口会退出启动器（如果下次提示端口 8765 被占用，双击 **`停止老师端.bat`** 即可）
- 如果提示端口被占用：双击 `停止老师端.bat` 后再双击一次启动
- 如果提示找不到 Python：说明这台电脑第一次用，需要先装 Python 依赖（让技术人员执行一次 `python -m pip install python-docx lxml openpyxl`）

**方式 B：免安装绿色版（电脑没有 Python 也能用）**

拿 `dist\tas-web-portable.zip`（约 19 MB，可整个发给老师）：

1. 解压到任意目录（如 `D:\tas老师端`）
2. 双击解压目录里的 **`启动老师端.bat`** → 自动打开浏览器
3. 关闭窗口即退出；用法与方式 A 完全一样；整个目录可复制到别的 Windows 电脑

## 2. 把学生文件收齐

1. 微信里把学生发来的 `.docx` 逐个「另存为」到电脑上的**同一个文件夹**（例如 `D:\作业\第3次`）
2. 文件名建议保持「学号+姓名」的格式，方便识别和发反馈
3. `.doc` 文件请先用 Word「另存为」`.docx`（工具只收 `.docx`）

## 3. 批量检查

1. 浏览器页面 → **教师端：批量检查 + 班级汇总**
2. 「选择规范」选学院/课程对应的规则集
3. 点 **「选择整个文件夹（只收 .docx）」** 选第 2 步的文件夹；或把文件一起拖进虚线框
4. 可选（推荐）：
   - 把班级名单粘贴到 **「名单核对」** 输入框（每行「学号 姓名」）→ 自动核对缺交/重复/命名
   - 勾选 **「同时生成安全修复版」** → 批量生成 `*_fixed.docx`（只改格式，不改文字/文献）
   - 勾选 **「生成首页缩略图」** → 每份文档首页 PNG，嵌在 HTML 报告里（需 Word，较慢）
   - 勾选 **「文献真实性核验」** → 联网核验参考文献元数据（每份最多 5 条，较慢；不评价内容/不查重）
5. 点 **「批量检查」**

## 4. 看结果

页面会显示：

- 总份数、检查成功/失败、**通过率**
- 错误/警告/提示总数
- **共性问题 Top**（全班最常犯的格式问题）
- 逐份结果（每份文档的错误/警告/提示、结论、耗时）

## 5. 把反馈发给学生

点 **「学生反馈（zip）」** 下载并解压：

| 文件 | 用途 |
|---|---|
| `00_班级汇总.txt` | 班级通过率、共性问题、未通过名单（自己留档/发群里） |
| `反馈_学号_姓名.txt` | 每份文档一个 txt：结论 + 主要问题 + 修改建议，**直接复制或把文件发给对应学生** |

也可以下载 `batch.xlsx`（Excel 汇总，适合存档/统计）、`batch.html`（网页版报告，勾选缩略图后会带缩略图列）。

**缩略图 / 文献核验结果**（如果勾选了）：

- 结果页会显示**首页缩略图网格**（前 12 份），可下载 `thumbnails.zip`（含全部 PNG + 说明）
- 文献核验显示 verified / likely / not_found / error 计数，可下载 `refs-report.md` / `.json`
- 注意：`not_found` 只表示未在当前公开索引检索到（中文期刊覆盖有限），**不等于造假**，需人工核实

## 6. 名单核对、批量修复、缩略图与文献核验（可选）

**名单核对**（页面「名单核对」输入框粘贴名单，或命令行 `--roster 名单.txt/.xlsx`）：

- 自动识别：学号优先、无学号按姓名匹配
- 输出：**缺交名单 / 重复提交（含 `(1)`、副本等多余副本提醒）/ 匹配不到名单的文件 / 文件名缺少学号或姓名**
- 结果同时显示在页面，并可下载 `roster-report.txt`

**批量安全修复**（页面勾选「同时生成安全修复版」，或命令行 `--fix`）：

- 每份文档生成 `*_fixed.docx`，打包为 `fixed.zip`（含修复报告/修复汇总）
- 只改格式属性；**正文文字、参考文献、目录条目不动**；内容 hash 校验不变；原文件不覆盖
- 覆盖：页面/正文/标题/前置格式 + **表格单元格字体/字号/对齐/行距（TAB-002）**
- 修复前后错误数会显示在页面（例如 620 → 0）；老师可选择把修复版回传给学生

> 修复前建议先看检查结果；涉及文字/编号/题注/文献/表题位置的问题不会自动改（避免误改学生内容）。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 双击没反应/闪退 | 右键「以管理员身份运行」；或查看黑窗口里的报错 |
| 端口 8765 被占用 | 关掉之前的黑窗口/其他占用程序，再双击启动 |
| 文件检查失败 | 文件可能是 `.doc`、加密、损坏；用 Word 另存为 `.docx` 再试 |
| 修复/预览按钮提示 Word 相关 | 页面预览和一键修复需要电脑装 Microsoft Word；只做批量检查不需要 |
| 想换检查规范 | 在「选择规范」下拉里换；也可以在「规范管理」里上传新的规范文档生成规则 |
| 数据在哪 | 项目目录 `data/`（接龙数据）和系统临时目录（检查上传）；不要手动删 `data/` |
| 绿色版解压后打不开 | 确认解压完整（`python` 文件夹和 `tas-web.exe`/`python.exe` 都在）；被杀毒软件拦截时加入白名单 |
| 绿色版缩略图/预览失败 | 确认电脑装了 Microsoft Word；并把绿色版解压到**普通目录**（如 `D:\tas老师端`、桌面），不要放在受限/沙箱目录 |
| 文献核验很慢/失败 | 需要联网；每份默认核验前 5 条，可减少条数或先小批量；`not_found` 不是造假，需人工核实 |
| 想自己重新打包绿色版 | 运行 `powershell -ExecutionPolicy Bypass -File scripts\build_portable.ps1`，产物在 `dist\tas-web-portable.zip` |
| 名单/修复结果在哪 | 名单报告 `roster-report.txt`；修复包 `fixed.zip`（页面下载链接） |

## 8. 边界说明（可对学生/领导解释）

- 只检查**格式规范**，不评价内容质量，不查重、不检测 AI
- **不改文字、不改参考文献**；「一键修复」只生成格式修正副本
- 每个学生的文档只在本机处理，不上传到任何外部服务器（联网核验文献时只发题名/作者）
- 反馈里的问题来自学校/课程规范（38 条规则），可解释、可复核
