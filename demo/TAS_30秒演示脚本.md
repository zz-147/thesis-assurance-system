# TAS 30 秒演示脚本（面试/发给老师）

> 目标：30 秒内让面试官/老师看懂「规范文档 → 规则 → 批量检查 → 安全修复 → 学生反馈」。

## 演示前准备

- 打开 Web：双击 `启动老师端.bat`（或 `python -m tas web --port 8765`）
- 准备演示目录：`demo/提交/`（6 份生成论文，含重复/缺交/命名不规范）
- 准备名单：`demo/名单.txt`（8 人）
- 规则集选 `school_default`

## 30 秒台词与操作

| 秒 | 操作 | 台词（可直接念） |
|---|---|---|
| 0–5 | 首页教师端，展示「选择整个文件夹 / 拖拽 / 名单 / 修复 / 缩略图 / 文献核验」 | “老师收齐微信里的论文后，不用逐个打开 Word，直接把整个文件夹拖进来。” |
| 5–12 | 点「批量检查」，等待结果 | “一次批量检查 6 份，自动出通过率、错误/警告、共性问题 Top、每份的结论和耗时。” |
| 12–20 | 结果页看**缩略图列**、**修复包**、**学生反馈 zip** | “每份首页缩略图直接嵌在报告里；一键安全修复把 81 个错误降到 0，只改格式、内容 hash 不变。” |
| 20–30 | 打开 `feedback.zip` 里一份 `反馈_*.txt` | “学生反馈是逐份 txt，直接转发；名单核对还会告诉你谁没交、谁重复、文件名不规范。” |

## 一句话收尾

> “这不是一个文档转换工具，而是把老师收作业、检查、反馈、修复串成一条本机流水线；LLM 只负责从规范里抽规则，真正改文档由确定性代码执行并复检。”

## 备用数字（被追问时）

- 规则覆盖 38/38（P0 23/23、P1 15/15）；327 个测试。
- 演示班级：6 份 / 8 人；错误 **81 → 0**；缺交 3、重复 1；缩略图 6/6。
- 合成变异集：116 处注入 / 23 类，检出率 100%、误报 0/201 段。
- 文献核验：not_found ≠ 造假，中文期刊需人工核实。
- 视频/截图：`demo/演示报告_一页总结.pdf`、`demo/截图/`。
